# React Native ile API Tabanlı E-Ticaret Uygulaması

Bu proje, Mobil Programlama dersi kapsamında React Native ve Expo kullanılarak geliştirilmiştir.

## Projenin Özellikleri

- DummyJSON API üzerinden ürünlerin listelenmesi
- Ürün detaylarının görüntülenmesi
- Ürün arama
- Ürün puanlarının gösterilmesi
- İndirimli fiyat hesaplama
- Sepete ürün ekleme ve silme
- Ürün miktarını artırma ve azaltma
- Toplam sepet tutarının hesaplanması
- Sepetteki toplam ürün adedinin gösterilmesi

## Kullanılan Teknolojiler

- React Native
- Expo
- JavaScript
- Expo Router
- Context API
- useState, useEffect ve useContext
- Fetch API
- DummyJSON REST API

## Uygulama Ekranları

- Ürün Listesi
- Ürün Detayı
- Sepetim

## Kurulum ve Çalıştırma

Bağımlılıkları yüklemek için:

`npm install`

Uygulamayı Expo Go ile çalıştırmak için:

`npx expo start --go`

Terminalde oluşan QR kod Expo Go uygulaması ile okutularak proje çalıştırılabilir.
